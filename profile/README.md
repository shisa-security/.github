# Shisa

Shisa is a macOS menu-bar app that checks your Mac for common ways people get
compromised, and speaks up only when something needs a look. Every check runs
on your Mac, and files are never uploaded.

- **Download:** [shisa.dev](https://shisa.dev)
- **Report a bug or request a feature:** [shisa-security/feedback](https://github.com/shisa-security/feedback/issues)
- **Report a security issue:** privately, through [Report a vulnerability](https://github.com/shisa-security/feedback/security/advisories/new) or by email to huybuidac@gmail.com

Shisa is source-available, not open source. Shisa Pro includes read access to
the source code under the Shisa Source License 1.0.
